The spec for the eight approved wireframes — 1a, 1g, 1h, 1k, 1n, 1r, 1s, 1t — written as an Astro project. Tokens, file tree, content schemas, per-page anatomy and the motion rules. Everything here is static-first: no client framework, one CSS file of tokens, JS only for the four effects in §7.

01 · STACK DECISIONS
Output

output: 'static' — the whole site prerenders. Deploy anywhere (Pages, Netlify, Vercel).

Content

Projects, publications and posts are Content Collections in src/content/, typed with zod. No CMS.

Styling

One tokens.css + component-scoped <style> blocks. No Tailwind needed; if you add it, map the tokens in theme.extend.

Images

astro:assets <Image> for covers. The duotone wash is CSS, not baked into the file.

02 · TOKENS — src/styles/tokens.css

Every value the wireframes use. Nothing else gets hard-coded downstream. Green is the only hue; contrast targets are noted so the "must be readable" requirement survives implementation.

:root {
  /* ground + structure */
  --bg:        #0a0b0a;   /* page */
  --surface:   #0d100e;   /* panels, rail */
  --line:      #24302a;   /* hairline, structural */
  --line-2:    #2b3a2f;   /* hairline, framed objects */

  /* type — 12.6:1 and 6.1:1 on --bg */
  --text:      #d7ded8;
  --text-dim:  #8b978f;
  --text-mute: #6d7a72;   /* labels only, never paragraphs */

  /* accent */
  --acc:       #57e08a;   /* 10.9:1 on --bg */
  --acc-hover: #8ff0b4;
  --acc-press: #3cb96c;
  --acc-line:  #4a6b56;   /* registration marks */
  --acc-wash:  rgba(87,224,138,.05);

  /* type */
  --font-head: 'Barlow Condensed', sans-serif;
  --font-body: 'Barlow', system-ui, sans-serif;
  --font-mono: 'IBM Plex Mono', ui-monospace, monospace;

  /* rhythm — 4px base */
  --s-1:4px; --s-2:8px; --s-3:12px; --s-4:16px;
  --s-5:24px; --s-6:32px; --s-7:48px; --s-8:72px;

  --rail: 168px;          /* 1k */
  --measure: 68ch;        /* prose cap */
  --radius: 0;            /* square corners, always */
}
READABILITY FLOOR

Body copy never below 15px / 1.65. --text-mute is for uppercase mono labels at 10–11px only. Accent green is never used for paragraph text on tinted fills — use --text there.

FRAME RULE

Any framed object (card, figure, primary button) carries a 1px --line-2 border and four + marks. Never rounded, never surface-filled — the one exception is the primary button's solid accent fill.

04 · CONTENT SCHEMAS — src/content/config.ts

The schema is the contract between your writing and the layouts. Add a project by adding a file; the home page, index and case-study route all pick it up.

import { defineCollection, z } from 'astro:content';

const projects = defineCollection({
  type: 'content',
  schema: ({ image }) => z.object({
    title: z.string(),
    order: z.number(),                     // index sort, ascending
    year: z.number(),
    summary: z.string().max(180),          // 1g preview + 1a row
    stack: z.array(z.string()),
    role: z.string(),
    period: z.string().optional(),         // "2026.02 — 2026.05"
    status: z.enum(['shipped','active','archived']).default('shipped'),
    cover: image().optional(),
    links: z.object({
      repo:  z.string().url().optional(),
      live:  z.string().url().optional(),
      paper: z.string().url().optional(),
    }).default({}),
    featured: z.boolean().default(false),   // shows on 1a
    draft: z.boolean().default(false),
  }),
});

const publications = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    authors: z.array(z.string()),
    venue: z.string(),
    year: z.number(),
    doi: z.string().optional(),
    pdf: z.string().optional(),
    kind: z.enum(['journal','conference','preprint','thesis']),
  }),
});

const posts = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    date: z.date(),
    tag: z.enum(['research','notes']),
    summary: z.string().optional(),
    draft: z.boolean().default(false),
  }),
});

export const collections = { projects, publications, posts };

<div class="index" data-selected="0">
  <ul class="rows">
    {projects.map((p, i) => (
      <li><a href={`/projects/${p.slug}`} data-i={i}
             aria-describedby="preview">{p.data.title}</a></li>
    ))}
  </ul>
  <aside id="preview" aria-live="polite">
    {projects.map((p, i) => <article data-i={i} hidden={i !== 0}>…</article>)}
  </aside>

<script>
  const root = document.querySelector('.index');
  const links = [...root.querySelectorAll('a[data-i]')];
  const panes = [...root.querySelectorAll('article[data-i]')];
  const select = (i) => {
    i = Math.max(0, Math.min(links.length - 1, i));
    root.dataset.selected = i;
    panes.forEach(p => p.hidden = +p.dataset.i !== i);
  };
  links.forEach((a, i) => {
    a.addEventListener('mouseenter', () => select(i));
    a.addEventListener('focus', () => select(i));
  });
  addEventListener('keydown', (e) => {
    if (e.key === 'j' || e.key === 'ArrowDown') links[Math.min(+root.dataset.selected + 1, links.length - 1)].focus();
    if (e.key === 'k' || e.key === 'ArrowUp')   links[Math.max(+root.dataset.selected - 1, 0)].focus();
  });
</script>

Every row is a real <a>, so the page works with JS off — all previews render, the first is shown, the rest are hidden. Below 860px drop the preview column entirely and inline the summary under each row.

07 · THE FOUR EFFECTS — AND THEIR LIMITS

All four are decoration layered over content that already reads. Each one sits behind prefers-reduced-motion and behind a no-js fallback that is simply the static state.

Type-on / decrypt

Only on the 1a prompt and the 1a name. Reveal by clipping a wrapper whose text is already in the DOM; cap at 700ms. Never on nav, never on body copy, never twice per page.

Scanlines / CRT

One fixed pointer-events:none overlay: 2px repeating-linear-gradient at opacity ≤ .05, plus an optional 0.5% vignette. No flicker animation on text — it destroys readability. Test small mono at 100% zoom before keeping it.

Hover reveal

1g only, and it must be duplicated onto :focus-visible — otherwise the page is keyboard-dead. Preview swaps are instant; no fades over 120ms.

Cursor-tracked grid

Background only, home band one. A CSS radial-gradient mask over a 32px grid, driven by two custom properties set on pointermove — rAF-throttled, dropped entirely on touch and on reduced-motion.

/* base.css — the global escape hatch */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation: none !important; transition: none !important; }
  .scanlines, .cursor-grid { display: none; }
}
:focus-visible { outline: 2px solid var(--acc); outline-offset: 2px; }
::selection { background: rgba(87,224,138,.25); color: var(--text); }
